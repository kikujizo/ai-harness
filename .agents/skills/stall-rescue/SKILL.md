# stall-rescue: 停滞案件の安全な診断と最小再開手順

同じ検証が繰り返し失敗し、修正のたびに失敗箇所が別の層へ移動する案件では、
「目の前のエラーを直す」こと自体が停滞を延命させる。
本Skillは、一次資料から停滞構造と律速を整理し、安全に試せる最小の再開手順を提示するプレイブックである。

役割分担・verdict・リスク定義の正本はルートの `AGENTS.md`。本Skillは再掲しない。

## 発動条件（いずれか1つで候補）

次の**いずれか**を満たすとき、発動候補とする（すべての条件の同時成立は不要）。

1. 同じタスクで、実質的に**同種の失敗または無進展が2回以上**続いた
2. 試行回数は増えているが、失敗層・停止理由・検証対象が整理されていない
3. ユーザーまたはIssueが `stall-rescue` を**明示指定**した

**補足**: 失敗層の移動は発動の必須条件ではない。移動が確認された場合は発動チェックポイント表の
「失敗理由が試行ごとに移動したとき」に該当する。

入力として使う証拠は、Issue、PR、コミット、テスト結果、CIログ、実機観測などの一次資料。
secret、token、個人情報、社内機密、外部サービスの実メッセージ本文はGitHubへ転載しない。

## 非発動条件

次のいずれかに該当する場合は、本Skillを発動せず通常フローに留まる。

- **同種失敗が1回のみ**（初回失敗）→ 通常のデバッグへ
- 仕様判断・要件の曖昧さが主因 → ChatGPT（仕様化）または `pm-review` へ
- 停滞状態を一次資料で確認できない（失敗が2回未満、履歴が取得不能）
- 通常のPMルーティング・実装・レビューで十分な単発タスク

## 発動チェックポイント（瞬間 → 行動）

`SKILL.md` の description と併せ、次の「瞬間 → 行動」を満たすときに発動候補とする
（PR #107 暫定repository-policy: 瞬間特定型descriptionと本表をセットで使う）。

| 瞬間 | 行動 |
|---|---|
| 2回目の同種失敗を確認した直後 | 再修正前に履歴と失敗層を時系列化する |
| 失敗理由が試行ごとに移動したとき | 製品側と測定側を分けて仮説化する |
| 実機・承認・待ち時間が次の試行を支配すると判明したとき | 予備検証経路を先に設計する |
| 安全契約を弱めれば通る案が出たとき | 採用せず、契約変更を別判断へ分離する |
| 根本原因を断定する直前 | 一次資料、反証結果、未確認事項を再照合する |

## プレイブック（この順で実行する）

### 手順1: 問いの格上げ

目の前のエラーではなく、システムの最終到達状態から失敗中の検証を位置づける。
一次資料（README・設計文書・Decision Log・Issue）から最終像→フェーズ構造→対象の位置づけを再構成し、
**失敗している検証が本質的な問いのどれに対応するかを地図化**する。

### 手順2: 全履歴の時系列化

試行、変更、失敗層、停止理由を一次資料から並べ、
「失敗層の移動回数」「同一失敗の再発」を数える。同一失敗と失敗層移動を区別する。

### 手順3: 観測ファースト

期待値と実機のズレが疑われる箇所は、推論や修正より前に**読み取り専用の実機観測**で反証する。
「実機で1コマンド見れば確定すること」を推論で埋めない。

### 手順4: 律速の特定と除去

1回の試行に必要な承認・実機・待ち時間・利用枠を確認し、
予備検証と本番検証を分離する。律速を除去するローカル反復ループを先に設計する。

### 手順5: 最小スコープ＋ガバナンス優先

確認済みバグ修正と契約変更を分離する。承認済みの安全契約（fail-closed設計）は、
成功率向上のために弱めない。契約変更をしたくなったら、実測証拠を添えて人間の判断にかける別件とする。

## 出力（必須。分離して提示する）

1. **最終到達状態**と、現在失敗している検証の位置
2. **時系列化した確定事実**と、確認不能な点
3. **停滞の律速候補**と、反証可能な原因仮説
4. **読み取り専用または完全に戻せる最小確認手順**
5. **続行・停止・PM再ルーティングの条件**

## 証拠不足・停止条件

次のいずれかに該当する場合、根本原因を推定で断定しない。

- 一次資料を取得できない
- 同種失敗が2回未満
- 停滞状態を確認できない

この場合は `確認不能` と不足証拠を明示し、通常のデバッグまたはCodex PM判断（`pm-review`）へ戻す。
権限拡大、安全契約の緩和、本番実行を解決策として自動提案しない。
